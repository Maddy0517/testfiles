QUICK START - Windows Users
============================

OPTION 1: Eclipse IDE (Easiest for Development)
================================================

1. Install Java 21 JDK
   Download: https://adoptium.net/

2. Install Eclipse IDE
   Download: https://www.eclipse.org/downloads/

3. Import Project
   - File → Import → Maven → Existing Maven Projects
   - Browse to project folder
   - Finish

4. Configure & Run
   - See ECLIPSE_SETUP.md for detailed instructions
   - Right-click WorkdayDataflowPipeline.java → Run As → Java Application


OPTION 2: Windows CMD (For Production)
=======================================

1. Install Prerequisites
   - Java 21 JDK: https://adoptium.net/
   - Maven: https://maven.apache.org/download.cgi
   - Verify: java -version && mvn -version

2. Setup Credentials
   - Edit: set-credentials.bat
   - Update with your Workday API details

3. Run Locally (Testing)
   set-credentials.bat
   run-local.bat

4. Run on Dataflow (Production)
   set-credentials.bat
   run-dataflow.bat


BATCH FILES PROVIDED:
=====================
✅ set-credentials.bat - Set environment variables
✅ run-local.bat - Run locally for testing
✅ run-dataflow.bat - Run on Google Cloud Dataflow
